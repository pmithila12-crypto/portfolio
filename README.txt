MITHILA PORTFOLIO — FILE SETUP

Files:
- index.html  : website structure
- style.css   : all styling and animations
- script.js   : menu, welcome animation, quotes, dice roller, scroll reveal, cursor and year
- images/     : put your real profile photo here

IMPORTANT — PROFILE PHOTO
The uploaded HTML code does not contain the actual photo file; it only refers to a photo path.
To display your photo:
1. Copy your real photo into the images folder.
2. Rename it exactly: mithila.png
3. The final path should be: images/mithila.png
If your photo is JPG, you can instead change the image src in index.html to:
images/mithila.jpg
Use the exact extension that Windows shows (for example, .jpg or .png).

HOW TO RUN
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html.
4. Right-click index.html and choose "Open with Live Server" (if installed), or open it in your browser.

Replace placeholder social links such as YOUR_USERNAME, YOUR_PHONE_NUMBER and YOUR_EMAIL with your actual details.
